%% 01INTRODUCTION

This documentation provides the details of version 0 of the perception model which is an Assume-Guarantee
contracts based model captured in AADL with the AGREE annex~\cite{}. This document details the contexts e.g. mission
scenario, operator task, and the intended scope of applicastion in section~\ref{sec:background}.  
We also provide background information on the class of formal method tools that we use to capture and analyze. 

Section~\ref{sec:model} describes the formal model in details including the devised HSR protocol need to validate 
the operator portion of the formal model. 

Section~\ref{sec:analysis} describes the result of the security analysis and shows the CEX which represents a 
possible attack that the HMD failed to prevent. 

Section~\ref{sec:refine} describes the future refinements or extensions of the model including more 
complexities on the device and operator.
